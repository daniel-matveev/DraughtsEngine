# Draughts Project

This is my Computer Science NEA project, where I coded a standard game of Draughts and built bots that use different algorithms to determine the next best possible move.

Algorithms used:
- Minimax
- AlphaBeta Prunning
- Monte Carlo Tree Search

Along with a recursive move generation algorithm to determine all valid move positions, and determine which pieces would have to be taken using backtracking.
